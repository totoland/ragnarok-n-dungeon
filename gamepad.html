Buttons — lit while held, labelled with the action Dungeon RO binds

Index 0 is whichever button sits at the bottom of the face cluster. On an Xbox pad that's A; on a Switch Pro Controller it's B. So jump lands on B and attack on Y unless you rebind them in the game's settings.

Axes — 0 and 1 are the left stick, which drives movement
If nothing shows up
  1. Open this in a real browser. An embedded viewer or a cross-origin iframe blocks the Gamepad API by policy and always reports nothing, whatever is connected.
  2. Put the pad in pairing mode properly. On a Switch Pro Controller that's the small round sync button on the top edge beside the USB-C port — hold ~3s until the four lights run back and forth. Home or a face button only tries to reconnect to a Switch.
  3. Use Bluetooth, not the cable. Over USB the Pro Controller doesn't speak standard HID — it waits on a Nintendo handshake desktop OSes don't send.
  4. Check the OS sees it first. It must appear in System Settings → Bluetooth before any browser can see it. Absent there means the problem is below the browser.
  5. Click this page once, then press a button. The API stays silent until the document has focus and has had a real press.
